# Third-party notices

## thinking-orbs (visual adaptation)

PreBase adapts the visual language of thinking-orbs for a single shared
activity indicator in the Webview.

- Upstream (fork designated for PreBase): https://github.com/Qtrick/thinking-orbs-for-PreBase-
- Upstream project: https://github.com/RareFormLabs/thinking-orbs
- License: MIT © Jakub Antalik

The adaptation lives in the Webview bundle. It is not used as a graph engine,
layout system, or per-node renderer.

## Rust and npm dependencies

Licenses for crates and npm packages are distributed with their upstream
packages. The packaged VSIX bundles the PreBase engine binary and Webview
assets built from this repository.
